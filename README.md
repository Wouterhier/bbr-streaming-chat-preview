# Body by Ravi — isolated mock chat preview

Public interface preview only. **No live messages, appointments, GoHighLevel, PatientNow, n8n, patient data, credentials, analytics, tracking, or backend endpoints.**

All responses, availability, and booking confirmations are simulated in browser memory. The discovery-call calendar uses `America/Chicago`; no patient timezone is inferred from a phone number. Contact fields are never persisted or transmitted.

The private engineering source, tests, metrics, and deployment records are maintained separately. This public package contains only the static files required for the mock preview and the stock-image license notice.
